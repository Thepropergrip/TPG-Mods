TPG Zolfaghar 1.02 · Release Candidate

Twin-missile ballistic launcher for DCS World, with HE and CM versions, inclined launches, animated warhead separation, heat glow, custom infrared materials and a burned destroyed model.

Close DCS. Extract the ZIP and copy the TPG Zolfaghar folder into your OVGME mods folder. Enable it using a configuration rooted at your active Saved Games/DCS folder, then start DCS. Keep Mods and Scripts together; the included visual controller is required. No files are installed into the DCS World folder.

See README.md inside Mods/tech/TPG_Zolfaghar/ for mission setup and CREDITS.txt for model attribution.
