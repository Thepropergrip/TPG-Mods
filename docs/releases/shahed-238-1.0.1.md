TPG Shahed-238 GPS / ASM 1.0.1

Ground-launched Shahed-238 drones for DCS World, with GPS and anti-ship launcher variants and up to five shots per launcher.

Close DCS, extract the original TPG_Shahed238_Rail folder into your active Saved Games/DCS/Mods/tech/ profile, then restart DCS. Find TPG Shahed-238 GPS and TPG Shahed-238 ASM in the Artillery category. Original Green and Sand Tan liveries are included.

The supplied DCS settings declare a 20–1,000 km launch envelope, 500 km/h cruise speed, 300 m cruise height and ten-minute shot/reload interval. These are configured values, not verified full-range flight performance. Terrain and obstacles can affect a flight.

Version 1.0.1 comes from entry.lua. The README retains its original 1.0.0 heading. All 58 supplied files, the original installation folder name and the included credits are preserved without modification in TPG_Shahed238_Rail.zip.
